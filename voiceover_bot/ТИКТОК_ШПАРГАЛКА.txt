ГЛАВНОЕ: видео собирает ТВОЙ компьютер (python), а не Клод. Подписка
Клода нужна была только чтобы писать код. Для создания видео она НЕ нужна.
Пока на компе есть папка проекта и Python — делаешь ролики сколько хочешь.

--------------------------------------------------------------------
ЧТО НУЖНО ОДИН РАЗ (у тебя уже стоит, это на случай нового компа)
--------------------------------------------------------------------
1. Установить Python 3.10+  (python.org, при установке галка "Add to PATH").
2. Открыть PowerShell в папке проекта и поставить библиотеки:
     cd C:\Users\User\Downloads\bot-code\--claude-festive-euler-ioure0\voiceover_bot
     pip install -r requirements-auto.txt
     python -m playwright install chromium
3. Ключи Яндекса (если делаешь голосом Яндекса) — один раз:
     setx YANDEX_API_KEY "твой_ключ"
     setx YANDEX_FOLDER_ID "твой_folder_id"
   (после setx закрой и открой PowerShell заново)

--------------------------------------------------------------------
ШАГ 1. ПОДГОТОВИТЬ 2 ФАЙЛА
--------------------------------------------------------------------
1) Картинка вопроса (скрин карточки) — например в Загрузки: вопрос.png
2) Текст озвучки — на Рабочем столе: тикток.txt   формат:

     <текст вопроса, который читает голос>
     Пояснение: <твой разбор — что голос объясняет>
     Ответ: <что голос говорит в конце>

   Варианты в тексте НЕ пишешь (они на картинке). Стрелки НЕ нужны —
   ты их сам добавляешь при монтаже.

--------------------------------------------------------------------
ШАГ 2. КОМАНДА СБОРКИ
--------------------------------------------------------------------
   cd C:\Users\User\Downloads\bot-code\--claude-festive-euler-ioure0\voiceover_bot

   python tiktok.py "C:\Users\User\Downloads\вопрос.png" "C:\Users\User\Desktop\пдд тик ток\tiktok.mp4" --speak "C:\Users\User\Desktop\тикток.txt" --engine edge --voice ru-RU-DmitryNeural --rate +5% --think 5 --correct 1

ЧТО МЕНЯТЬ под каждый ролик:
  • путь к картинке   — своё имя файла
  • путь к выходному mp4 — назови как хочешь (tiktok2.mp4 и т.д.)
  • путь к тикток.txt — твой текст
  • --correct 1       — НОМЕР правильного варианта (1, 2, 3 …).
                        Программа сама найдёт этот вариант на картинке и
                        зажжёт его зелёным после слова "Ответ".
  • --think 5         — длина таймера в секундах (5, 7 …)
  • --rate +5%        — скорость голоса (+10% быстрее, 0% обычная)

ПОРЯДОК В РОЛИКЕ:
  голос читает вопрос → таймер N сек (круг + тик-тик) → разбор →
  "Ответ ..." → после последнего слова загорается зелёная полоска.

--------------------------------------------------------------------
ГОЛОС
--------------------------------------------------------------------
• Дмитрий (Майкрософт): --engine edge --voice ru-RU-DmitryNeural
    Нужен ВКЛЮЧЁННЫЙ VPN/WARP (провайдер режет Майкрософт).
    Если ошибка "NoAudioReceived" — включи VPN или перейди на Яндекс.
• Яндекс (не режется провайдером): --engine yandex --voice filipp
    Нужны ключи YANDEX_API_KEY / YANDEX_FOLDER_ID (см. выше).

--------------------------------------------------------------------
ЕСЛИ ЗЕЛЁНАЯ ПОЛОСКА ЛЕГЛА НЕ ТУДА
--------------------------------------------------------------------
Проверь позицию до сборки видео (режим сетки, выходной файл .png):
   python tiktok.py "картинка" setka.png --speak "тикток.txt" --correct 1 --grid
Открой setka.png — зелёная рамка должна лечь на правильный вариант.
Если номер не тот — поменяй цифру в --correct.
Если детектор не нашёл бокс — поставь вручную в текст тег:
   {зелёный:0.67,0.10}        (0.67 = высота сверху, 0.10 = высота полоски)
