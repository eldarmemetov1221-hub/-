# 🎙 Telegram-бот для озвучки видео

Бесплатный бот: пишешь текст — получаешь готовый **mp3** с реалистичным
человеческим голосом. Русский и английский.

Работает на **edge-tts** — нейроголоса Microsoft Edge. Полностью бесплатно,
**без API-ключей, регистраций и лимитов**.

## Возможности

- Реалистичные нейроголоса (муж./жен.), русский и английский (US/UK)
- `/voice` — выбор голоса кнопками
- `/rate +15%` — скорость чтения (от `-50%` до `+100%`)
- `/pitch -15Hz` — тон голоса
- Настройки запоминаются для каждого пользователя
- Готовый mp3 сразу можно вставлять в видео

## Установка

1. **Получи токен бота.** В Telegram напиши [@BotFather](https://t.me/BotFather) →
   `/newbot` → придумай имя → скопируй токен.

2. **Установи зависимости** (нужен Python 3.10+):

   ```bash
   cd voiceover_bot
   pip install -r requirements.txt
   ```

3. **Запусти:**

   ```bash
   export BOT_TOKEN="сюда_токен_от_BotFather"
   python bot.py
   ```

   (На Windows: `set BOT_TOKEN=...` вместо `export`.)

4. Открой своего бота в Telegram, нажми **/start** и пришли ему текст.

## Как пользоваться

1. `/voice` — выбери голос.
2. (по желанию) `/rate +10%` и `/pitch -10Hz` — подстрой звучание.
3. Пришли текст → получи mp3.

## 🎤 Клонирование голоса (свой голос) — необязательно

Бот умеет озвучивать текст **твоим собственным голосом**: записываешь образец —
дальше читает им любой текст. Работает на **XTTS v2** (бесплатно, локально,
поддерживает русский). Это тяжёлый модуль — включается отдельно.

**Что нужно:** видеокарта NVIDIA (желательно), ~3 ГБ на диске под модель.

**Установка (один раз):**

1. Поставь torch с поддержкой CUDA (для видеокарты NVIDIA):

   ```bash
   pip install torch --index-url https://download.pytorch.org/whl/cu121
   ```

   (Без NVIDIA — просто `pip install torch`, будет работать на процессоре, медленнее.)

2. Поставь пакеты клонирования:

   ```bash
   pip install -r requirements-clone.txt
   ```

**Как пользоваться:**

1. Запусти бота (`python bot.py`) — в логах будет `клонирование: включено`.
2. В боте нажми **🎤 Мой голос**.
3. Запиши голосовое (15–30 сек, чётко, без шума) — бот даст текст для чтения.
4. Пришли любой текст — бот озвучит его твоим голосом.

> ⚠️ Первая озвучка скачивает модель (~2 ГБ) и идёт несколько минут — дальше быстро.
> ⚠️ Клонируй **только свой** голос или голос с разрешения — не выдавай синтез за
> реального человека.

## Добавить другие голоса

Полный список голосов:

```bash
edge-tts --list-voices
```

Добавь нужный в `voices.py` — там же примеры.

## Частые вопросы

- **Точно бесплатно?** Да. edge-tts использует публичный сервис озвучки Edge,
  ключи не нужны.
- **Нужен интернет?** Да, синтез идёт онлайн.
- **Ошибка «Не задан BOT_TOKEN»** — не выставлена переменная `BOT_TOKEN`.
