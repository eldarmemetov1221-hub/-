# 🎙 Telegram-бот для озвучки видео

Бесплатный бот: пишешь текст — получаешь готовый **mp3** с реалистичным
человеческим голосом. Русский и английский.

Работает на **edge-tts** — нейроголоса Microsoft Edge. Полностью бесплатно,
**без API-ключей, регистраций и лимитов**.

## Возможности

- Реалистичные нейроголоса (муж./жен.), русский и английский (US/UK)
- `/voice` — выбор голоса кнопками
- `/rate +15%` — скорость чтения (от `-50%` до `+100%`)
- `/pitch -15Hz` — тон голоса
- Настройки запоминаются для каждого пользователя
- Готовый mp3 сразу можно вставлять в видео

## Установка

1. **Получи токен бота.** В Telegram напиши [@BotFather](https://t.me/BotFather) →
   `/newbot` → придумай имя → скопируй токен.

2. **Установи зависимости** (нужен Python 3.10+):

   ```bash
   cd voiceover_bot
   pip install -r requirements.txt
   ```

3. **Запусти:**

   ```bash
   export BOT_TOKEN="сюда_токен_от_BotFather"
   python bot.py
   ```

   (На Windows: `set BOT_TOKEN=...` вместо `export`.)

4. Открой своего бота в Telegram, нажми **/start** и пришли ему текст.

## Как пользоваться

1. `/voice` — выбери голос.
2. (по желанию) `/rate +10%` и `/pitch -10Hz` — подстрой звучание.
3. Пришли текст → получи mp3.

## 🎬 Озвучка видео по сценам (умная привязка)

Бот накладывает озвучку на видео (например, запись экрана билетов ПДД без звука).
Он **смотрит на содержимое кадра** и ловит момент, когда сменился вопрос, затем
ставит текст по порядку: абзац №1 → 1-й вопрос, абзац №2 → 2-й вопрос и т.д.

Текст дели **пустой строкой на абзацы — один абзац на один вопрос/задание**.

**Через бота (видео до 20 МБ):**
Пришли боту **видео с подписью**, в подписи — текст абзацами. Бот вернёт mp4 и
напишет, сколько моментов нашёл.

**Скриптом (видео любого размера) — рекомендуется для записей ПДД:**
Telegram не даёт ботам качать файлы больше 20 МБ, поэтому длинные записи делай на ПК:

```bash
# 1) сначала ПРЕДПРОСМОТР — проверить, сколько вопросов нашлось и на каких секундах
python make_video.py видео.mp4 текст.txt --preview

# 2) если моменты совпали с числом абзацев — запускаем озвучку
python make_video.py видео.mp4 текст.txt

# с настройками:
python make_video.py видео.mp4 текст.txt итог.mp4 --voice ru-RU-SvetlanaNeural --rate +10%
```

Готовый файл появится рядом с исходным (`видео_voiced.mp4`).

**Подбор чувствительности** (если моменты находятся не идеально):
- `--threshold 0.02` — ловит больше смен (чувствительнее),
- `--threshold 0.06` — меньше (только явные смены),
- `--min-gap 3` — минимум секунд между вопросами (убирает ложные срабатывания подряд).

Всегда сначала гоняй `--preview` на записи — увидишь список моментов и подберёшь
параметры за пару секунд, не пересчитывая всю озвучку.

### 🔤 Максимальная точность — OCR (необязательно)

Если поставить OCR, бот будет **читать номер вопроса** на экране («Вопрос 5») и
определять смену по номеру — самый надёжный вариант, не зависит от анимаций.

```bash
pip install pytesseract
```

Плюс установи саму программу **Tesseract OCR** с русским языком:
Windows — https://github.com/UB-Mannheim/tesseract/wiki (при установке отметь
«Russian»). После этого OCR подхватится автоматически.

## 🤖 Авто-запись билета — БЕЗ ручной записи экрана (`auto_quiz.py`)

Не надо больше сидеть 15 минут, вручную читать вопросы, водить мышкой, жать
ответы и переписывать дубли. Даёшь **готовый текст билета** — скрипт сам
проходит билет в браузере и отдаёт готовое озвученное видео.

Что делает:

1. Разбирает текст на 20 вопросов (вопрос, варианты, правильный ответ, пояснение).
2. Озвучивает каждый **голосом Дмитрия** (edge-tts, средний темп, паузы по
   знакам препинания).
3. Сам «проходит» билет в браузере: показывает вопрос, ведёт курсор к
   правильному варианту, зажигает его **зелёным**, идёт таймер и «Вопрос N/20» —
   как настоящая запись экрана.
4. Держит каждый вопрос **ровно столько, сколько длится озвучка** — голос
   никогда не наезжает на следующий вопрос (синхрон идеальный, без таймкодов).
5. Пишет видео и накладывает озвучку → готовый `.mp4`.

**Установка (один раз):**

```bash
cd voiceover_bot
pip install -r requirements-auto.txt
python -m playwright install chromium
```

**Запуск** (включи VPN — edge-tts ходит к Microsoft):

```bash
python auto_quiz.py bilet1.txt bilet1.mp4
```

Полезное:

- `--rate +8%` — чуть быстрее (средний темп; по умолчанию обычный).
- `--pad 1.4` — сколько секунд держать зелёный ответ после озвучки.
- `--reveal 0.5` — в какой доле вопроса зажигать зелёный (0.5 = на середине).
- `--width 1920 --height 1080` — размер видео (по умолчанию 1280×720).
- `--dump-page макет.html` — только сохранить страницу-макет, чтобы глазами
  проверить вид, без записи.
- `--engine silero` — офлайн-голос, если edge-tts заблокирован (голос другой).

**Формат текста** (по заголовкам — гибко):

```
Вопрос 1
Разрешён ли Вам обгон в данной ситуации?
1. Разрешён
2. Запрещён
Ответ: 2
Пояснение: Обгон запрещён на пешеходном переходе.

Вопрос 2
...
```

Заголовок — «Вопрос 1», «1.», «1)», «Билет 5 вопрос 1». Варианты — строки с
«1.», «2)», «- », «а)». `Ответ:` — номер (или текст) правильного варианта.
`Пояснение:` — пояснение. Если вариантов нет — просто покажет вопрос и
пояснение, а озвучит весь блок.

### Вариант с твоим сайтом pdd-exam.ru (`site_quiz.py`)

Если хочешь, чтобы картинка была **родная с сайта** (как в билетах 1-5) —
`site_quiz.py` открывает настоящий билет на pdd-exam.ru, сам его проходит
(жмёт правильные ответы, зелёный загорается на сайте), прячет рекламу/шапку и
записывает, а сверху кладёт озвучку Дмитрия.

Сначала **разведка** (один раз, чтобы точно подогнать под сайт) — покажет
структуру и сохранит скриншоты:

```bash
python site_quiz.py 6 bilet6.txt --inspect
```

Потом запись:

```bash
python site_quiz.py 6 bilet6.txt bilet6.mp4
```

Где `6` — номер билета, `bilet6.txt` — твой текст (тот же формат, что выше).
Правильный ответ жмётся **по совпадению текста** варианта из твоего текста с
кнопкой на сайте (порядок вариантов на сайте может отличаться — не страшно).
Полезное: `--pad 1.6` (дольше держать зелёный), `--rate +8%` (чуть быстрее),
`--width 1920 --height 1080` (Full HD).

## 🎤 Клонирование голоса (свой голос) — необязательно

Бот умеет озвучивать текст **твоим собственным голосом**: записываешь образец —
дальше читает им любой текст. Работает на **XTTS v2** (бесплатно, локально,
поддерживает русский). Это тяжёлый модуль — включается отдельно.

**Что нужно:** видеокарта NVIDIA (желательно), ~3 ГБ на диске под модель.

**Установка (один раз):**

1. Поставь torch с поддержкой CUDA (для видеокарты NVIDIA):

   ```bash
   pip install torch --index-url https://download.pytorch.org/whl/cu121
   ```

   (Без NVIDIA — просто `pip install torch`, будет работать на процессоре, медленнее.)

2. Поставь пакеты клонирования:

   ```bash
   pip install -r requirements-clone.txt
   ```

**Как пользоваться:**

1. Запусти бота (`python bot.py`) — в логах будет `клонирование: включено`.
2. В боте нажми **🎤 Мой голос**.
3. Запиши голосовое (15–30 сек, чётко, без шума) — бот даст текст для чтения.
4. Пришли любой текст — бот озвучит его твоим голосом.

> ⚠️ Первая озвучка скачивает модель (~2 ГБ) и идёт несколько минут — дальше быстро.
> ⚠️ Клонируй **только свой** голос или голос с разрешения — не выдавай синтез за
> реального человека.

## Добавить другие голоса

Полный список голосов:

```bash
edge-tts --list-voices
```

Добавь нужный в `voices.py` — там же примеры.

## 🖥 Запуск на VPS (Ubuntu/Debian, 24/7)

Ставится **только базовый бот** (edge-tts) — лёгкий, не открывает портов, не
мешает сайту на том же сервере. Работает как служба systemd (автозапуск,
автоперезапуск, лимит памяти 400 МБ для защиты сайта).

По SSH на сервере:

```bash
# 1. инструменты
sudo apt update && sudo apt install -y git python3-venv

# 2. код (ветка с ботом)
cd ~
git clone -b claude/festive-euler-ioure0 https://github.com/eldarmemetov1221-hub/-.git voiceover
cd voiceover/voiceover_bot

# 3. токен (подставь свой)
echo 'BOT_TOKEN=твой_токен' > bot.env

# 4. установка + запуск как службы
bash deploy/install-vps.sh
```

Управление:

```bash
sudo systemctl status voiceover-bot     # статус
journalctl -u voiceover-bot -f          # логи в реальном времени
sudo systemctl restart voiceover-bot    # перезапуск
sudo systemctl stop voiceover-bot       # остановить
```

> ⚠️ Клонирование голоса (XTTS) на VPS ставить **не рекомендуется** — оно тяжёлое
> (2 ГБ модель, много RAM/CPU) и может уронить сайт. Держи клон на своём ПК.

## Частые вопросы

- **Точно бесплатно?** Да. edge-tts использует публичный сервис озвучки Edge,
  ключи не нужны.
- **Нужен интернет?** Да, синтез идёт онлайн.
- **Ошибка «Не задан BOT_TOKEN»** — не выставлена переменная `BOT_TOKEN`.
