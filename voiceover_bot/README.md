# 🎙 Telegram-бот для озвучки видео

Бесплатный бот: пишешь текст — получаешь готовый **mp3** с реалистичным
человеческим голосом. Русский и английский.

Работает на **edge-tts** — нейроголоса Microsoft Edge. Полностью бесплатно,
**без API-ключей, регистраций и лимитов**.

## Возможности

- Реалистичные нейроголоса (муж./жен.), русский и английский (US/UK)
- `/voice` — выбор голоса кнопками
- `/rate +15%` — скорость чтения (от `-50%` до `+100%`)
- `/pitch -15Hz` — тон голоса
- Настройки запоминаются для каждого пользователя
- Готовый mp3 сразу можно вставлять в видео

## Установка

1. **Получи токен бота.** В Telegram напиши [@BotFather](https://t.me/BotFather) →
   `/newbot` → придумай имя → скопируй токен.

2. **Установи зависимости** (нужен Python 3.10+):

   ```bash
   cd voiceover_bot
   pip install -r requirements.txt
   ```

3. **Запусти:**

   ```bash
   export BOT_TOKEN="сюда_токен_от_BotFather"
   python bot.py
   ```

   (На Windows: `set BOT_TOKEN=...` вместо `export`.)

4. Открой своего бота в Telegram, нажми **/start** и пришли ему текст.

## Как пользоваться

1. `/voice` — выбери голос.
2. (по желанию) `/rate +10%` и `/pitch -10Hz` — подстрой звучание.
3. Пришли текст → получи mp3.

## Добавить другие голоса

Полный список голосов:

```bash
edge-tts --list-voices
```

Добавь нужный в `voices.py` — там же примеры.

## Частые вопросы

- **Точно бесплатно?** Да. edge-tts использует публичный сервис озвучки Edge,
  ключи не нужны.
- **Нужен интернет?** Да, синтез идёт онлайн.
- **Ошибка «Не задан BOT_TOKEN»** — не выставлена переменная `BOT_TOKEN`.
